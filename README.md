# Rick AI Assistant — Privacy Policy

Static privacy-policy page for Rick AI Assistant, intended for Meta for Developers / WhatsApp Cloud API.

## Publish with GitHub Pages
1. Create a public GitHub repository named `rick-ai-assistant-privacy`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site.
7. Open the published HTTPS URL and use it as the Privacy Policy URL in Meta for Developers.
